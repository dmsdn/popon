# 팝온 현장 웨이팅 등록 (staff-checkin)

현장 태블릿에 띄워두고 쓰는 화면이에요. 이제 3단계 흐름이에요:

1. **`/` (로그인)** — 로고 + "현장 웨이팅" + 주최측(사업자) 이메일/비밀번호 로그인
2. **`/select-popup` (팝업 선택)** — 로그인한 사업자가 운영중인 팝업 목록에서 "웨이팅 시작하기"로 하나 선택
3. **`/checkin?popupId=X` (웨이팅 등록)** — 손님이 직접 전화번호/이메일 중 하나를 입력해서 웨이팅 등록

로그인 정보는 `sessionStorage`에 저장돼요 (브라우저를 완전히 닫으면 다시 로그인해야 해요 - 태블릿을
계속 켜둘 거라 이 정도면 충분할 거예요. 더 오래 유지하고 싶으시면 `lib/auth.ts`에서
`sessionStorage`를 `localStorage`로 바꿔주세요).

## 실행 방법

```bash
npm install
npm run dev
```

`http://localhost:5176` 에서 열려요 (기존 앱이 5173~5175를 쓰고 있어서 겹치지 않게 5176으로 뒀어요).

같은 폴더에서 백엔드(Spring Boot, 8080 포트)가 켜져있어야 정상 동작해요.


## ⚠️ 백엔드에 확인이 필요한 부분

`WaitingQueueService.register()`를 보면, **비회원(customerId 없이) 등록 시 이름과 이메일이 필수**예요:

```java
if (request.getName() == null || request.getName().isBlank()
        || request.getEmail() == null || request.getEmail().isBlank()) {
    throw new IllegalArgumentException("비회원 웨이팅은 이름과 이메일이 필수입니다.");
}
```

화면에는 전화번호 + **이메일**을 받도록 만들었어요 (이메일은 아이디+도메인 드롭다운 방식,
소비자 앱의 이메일 입력과 같은 디자인이에요). name 필드는 화면에 없어서 "현장고객"으로
고정해서 보내고 있어요 - 이름까지 받고 싶으시면 말씀해주세요, 입력칸 추가해드릴게요.

## 스타일

소비자 앱과 같은 색상 토큰(포인트 컬러 `#5bce41`, 배경 `#17181a`, 카드 `#282b32`)을 그대로 썼고,
다크모드만 있어요(라이트모드 토글 없음).

## 가로 화면 고정

브라우저 CSS만으로는 기기를 강제로 가로 방향으로 "잠그는" 게 안 돼요(그건 네이티브 앱이나,
전체화면 상태에서 Screen Orientation API 권한을 받아야 가능해요). 대신 태블릿을 세로로 들면
"가로로 돌려주세요" 안내 화면이 전체를 덮도록 만들어서, 사실상 가로 모드로만 쓰게 했어요.
